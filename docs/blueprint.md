# **App Name**: Cafe POS Express

## Core Features:

- Order Screen: Streamlined, touch-friendly order entry interface with customizable categories (food, drinks, desserts, shisha)
- Dashboard Overview: Dashboard providing real-time sales data and a quick overview of orders.
- Menu Management: Menu management interface allowing addition, editing, and categorization of menu items with options for pricing.
- Sales Reporting: Basic reporting for daily/monthly sales, top-selling items, and payment methods.

## Style Guidelines:

- Neutral background (light gray or beige) for comfortable readability over extended use.
- Accent color: Emerald green (#50C878) for calls to action and important alerts, conveying freshness and efficiency.
- Clean and modern sans-serif fonts for all text elements to ensure readability.
- Consistent and clear icons to represent categories, functions, and actions, for quick visual recognition.
- Simple, grid-based layout with clearly defined sections for easy navigation on touch screen devices.
- Subtle animations for feedback on button presses and screen transitions to enhance the user experience without being distracting.
